- 작성일: 2026-10-31
- 출처: Mobbin "Suno iOS" UI Elements 131장을 크롬으로 전부 넘기며 관찰 (https://mobbin.com/apps/suno-ios-78e3a1fd-0d14-43ff-88ee-89100d111d89)
- 용도: 티켓레이더(가칭) 상세 디자인의 **부품 모양·구조** 기준. 색 값은 화면에서 눈으로 읽은 근사치이며 ±몇 단계 오차가 있다. 기능(피드·재생·구독)은 가져오지 않고 모양만 가져온다.

## 2. 부품별 관찰

### 2-1. 주요 버튼 (Primary CTA) — 2026-10-31 확대 재관찰로 수정
- 가로 꽉 찬 알약(완전 둥근 모서리), 높이 약 48~52px.
- 바탕은 **선형 그라데이션이 아니다.** 분홍 `#FF2F74` 바탕 위에 빨간주황 `#FF5A2E`·주황 `#FF8A2B`·노랑 `#FFB42E` 덩어리가 안개처럼 번진 **플라즈마(용암) 질감**이고, 따뜻한 색 영역에 **거친 입자(grain)** 가 뚜렷하다. 버튼마다 같은 질감의 다른 부분이 잘려 나온 것처럼 덩어리 위치가 다르다(Confirm은 오른쪽 위 노랑, Continue는 왼쪽 주황 등). 테두리·그림자 없음.
- 글자: 흰색 16~17px **보통 굵기(Regular)**. 굵은 글씨가 아니다. 아이콘이 있으면 왼쪽에 흰색(♪✦ Create, → Extend).
- **비활성**: 짙은 회색 알약, 같은 질감이 아주 희미하게(약 10%) 비침, 글자 회색 `#6B6B70`.
- **만들기 화면의 배치**: 왼쪽에 지름 약 44~52px의 어두운 원형 버튼(휴지통, 흰 아이콘) + 오른쪽에 질감 알약이 남은 폭을 채움. 둘 사이 10~12px.
- 재현: `docs/suno-cta.glsl`(pen.dev 셰이더 fill). 코드에서는 같은 셰이더를 WebGL/CSS Houdini로 쓰거나, 이 셰이더로 뽑은 PNG를 `background-image`로 깐다.

### 2-1b. 라벨·배지 재관찰
- Suno는 **연한 바탕색 + 진한 글자**의 "틴트 배지"를 쓰지 않는다. 라벨은 두 가지뿐이다.
  - (a) **색 글자 + 작은 아이콘, 바탕 없음**: "♥ Most Popular"(초록), "★ Best Value"(노랑). 12~13px, 중간 굵기.
  - (b) **진한 단색 작은 상자 + 흰 대문자 글자**: "SAVE 20%"(분홍 `#FF3D8A`, 모서리 약 6px, 자간 넓음, 10~11px 굵게). 강조 1개에만.
- 우리 심각도 배지는 (a)로 간다: 아이콘 14px + 글자 13px, 바탕 없음. 정보 하늘색 `#7CC4FF` / 주의 노랑 `#FFC53D` / 확인 필요 주황 `#FF8A3D`(Suno가 선택된 구독 카드 테두리에 쓰는 주황 계열). 빨강 없음.
- 칩: "Instrumental", "Advanced"처럼 **1px 흰 15% 테두리 + 투명 바탕**이 기본 칩이고, 채운 칩은 흰 10~12% 반투명. 플레이어 행동 알약(👍 313)도 반투명 흰 바탕이라 뒷배경에 따라 톤이 변한다.
- 토스트: 흰 바탕, 모서리 약 10px, 검정 체크 원 + 15px 보통 굵기 검정 글자.
- 진행 알약: 어두운 반투명 알약 + 흰 글자 보통 굵기 + 오른쪽 **분홍 고리(ring) 스피너**(원 안이 비어 있음). 완료는 왼쪽 썸네일 + 오른쪽 분홍→주황 그라데이션 원 ▶.

### 2-2. 흰 버튼 (Secondary, 강조 보조)
- 흰 바탕 `#FFFFFF` 알약, 검정 글자 15px 중간 굵기, 높이 44~48px, 아이콘 왼쪽(G, 전화, Apple, ▶ Play, + Create & Add to Playlist).
- 로그인 선택, Play, Report, Done, Post, Save 등 "그 화면의 두 번째로 중요한 행동"에 씀.

### 2-3. 회색 버튼·대화상자
- 확인 대화상자: 어두운 카드 위 제목 16px 굵게 + 설명 13px 회색 + 버튼 두 개 나란히(어두운 회색 알약 "Cancel" 흰 글자 / 같은 모양에 **분홍 글자** "Report", 파괴적 행동은 빨간 글자 "Log out").

### 2-4. 칩 (Chips) — 2026-10-31 확대 재관찰로 수정
- 공통: 글자는 **보통 굵기 13px**, 굵은 글씨 없음. 바탕은 단색이 아니라 **흰색 반투명**(8~12%)이라 카드 위에서는 조금 밝아지고 검정 위에서는 어두워진다.
- **점선 테두리 칩**: 만들기(Simple) 화면의 "+ / Audio / Styles / Lyrics". 높이 36px, 좌우 14px, 아이콘 16 + 글자 13, 테두리 흰색 20~35% 점선(대시 5 / 간격 4 정도), 바탕 없음. "추가할 수 있는 것"을 뜻함. 재현: `docs/dashed-pill.glsl`.
- **채운 칩**: 스타일 태그(anthemic, pop rock, slow). 바탕 흰 8%, 글자 `#E6E6EA` 13px, 높이 32px, 좌우 12px, 테두리 없음.
- **테두리 칩(켜짐 상태)**: "Instrumental", "Advanced". 바탕 없음, 1px 흰 15% 테두리, 왼쪽 체크 원 아이콘 16 + 글자 13. 분홍은 쓰지 않는다.
- **세그먼트 2종**
  - 선택형 "Monthly / Annual": 높이 40, 안쪽 여백 3, 바탕 흰 8% 알약. 두 칸이 같은 폭, 선택된 칸만 흰 20% 알약 + 흰 글자 15/500, 나머지는 회색 글자. 위에 "SAVE 20%" 분홍 상자.
  - 행동형 "+ Audio | + Voice": 높이 44, 바탕 흰 8% 알약, 가운데 1px 세로선(흰 15%, 높이 20), 양쪽에 아이콘 16 + 글자 14 보통 굵기.

### 2-2b. 보조 버튼 치수 재관찰 (보관 캡처에서 픽셀 × 1.53 = pt 로 환산)
- 흰 알약: 높이 44(Play·Done), 가로 꽉 찬 것은 52(Report·Create & Add to Playlist). 좌우 20, 아이콘 16 검정 + 글자 15/500 검정.
- 회색 알약(플레이어 행동 줄 👍 313 / ⟳ Remix): 높이 34, 왼쪽 10·오른쪽 12, 바탕 흰 12%, 아이콘 16 + 글자 13 보통 굵기.
- 원형 아이콘 버튼(되돌리기·북마크·휴지통·뒤로가기): 지름 34, 바탕 흰 12%, 아이콘 16. 마법봉만 흰 원 + 검정 아이콘.
- 휴지통(Create 옆): 지름 46~48, 그 옆 Create 알약 높이 56, 사이 10. 온보딩 Continue/Confirm도 56.
- 흰 토스트 높이 52, 진행 알약("You always get two full songs") 높이 56.
- 상단 오른쪽 "v6-mini ▾" 알약: 높이 30, 왼쪽 12·오른쪽 8, 글자 13 + 아래 화살표 14.

### 2-5. 입력
- 큰 글 입력(전화번호·이름·재생목록 이름): **테두리 없음**, 가운데 정렬, 글자 20~24px, 분홍 커서만 보임. 자리표시 글자는 회색.
- 만들기 화면의 본문 입력: 카드 안에서 자리표시 "Write lyrics or a prompt, or leave empty for instrumental" 회색 15px. 테두리 없음.
- 검색: 어두운 알약 안에 돋보기 + 회색 자리표시.

### 2-6. 접히는 섹션 카드 (Lyrics / Styles / More Options)
- 카드 `#1C1C1F`, 모서리 16px, 안쪽 16px.
- 머리줄: 왼쪽 "⌄ Lyrics" 14px, 오른쪽에 지름 36px 원형 아이콘 버튼들(되돌리기·북마크·휴지통은 어두운 원, **마법봉은 흰 원에 검정 아이콘**).
- 본문: 입력 글 또는 자리표시.
- 바닥줄: 왼쪽 원형 아이콘 버튼 2개(라이브러리, 체크 칩 "Instrumental"), 오른쪽 끝 확대 아이콘.
- "More Options"는 같은 카드에 머리줄만 있고 펼치면 슬라이더 행이 나옴.

### 2-6b. 카드·행·대화상자 치수 (14:27 큰 확대본 `zoom/1793424430762~6-*.png`, 1px ≈ 0.81pt)
- **Simple 만들기 카드**: 바탕보다 조금 밝은 반투명 면, 모서리 20, 안쪽 16. 맨 위 "+" 원 36 + 점선 칩 36(Audio/Styles, 둘째 줄 Lyrics). 본문 글자 14~15 보통 굵기, 분홍 커서. 카드가 **주요 버튼 위까지 세로로 꽉 참**. 오른쪽 아래 "?" 원 36, 여백 16.
- **Advanced 섹션 카드(Lyrics/Styles)**: 모서리 20, 안쪽 16. 머리줄 "⌄ Styles" 14/500 + 원형 도구 36 ×4(되돌리기·북마크·휴지통 어두운 원, 마법봉 흰 원). 머리줄-본문 사이 20. 본문 14 보통, 줄간격 1.55, `#E8E8E8`. 바닥줄: 원 36(라이브러리·새로고침) + 채운 칩 36(ethereal, heavy metal) + 오른쪽 확대 원 36.
- **"› More Options" / "♪ Loose Change" 행**: 카드와 같은 면, 높이 약 60~64, 모서리 20, 왼쪽 chevron/아이콘 + 글자 14~15.
- **Create 줄**: 휴지통 원 54 + Create 알약 54(같은 높이), 사이 12~13.
- **More Options 슬라이더 행**: 행마다 둥근 상자(높이 57, 모서리 16), 왼쪽 라벨 12~13 + ⓘ, 가운데 눈금 7개 위 분홍 세로 알약 손잡이(15×32), 오른쪽 값.
- **대화상자(Delete your account / Log out / Report)**: 카드 폭 약 315~320, 모서리 16, 안쪽 16. 제목 15~16/600 왼쪽, 설명 12~13 회색. 버튼 2개 나란히 높이 44~46: 왼쪽 "Cancel"은 **더 밝은 회색(흰 20%)** 알약 흰 글자, 오른쪽 행동은 **더 어두운(흰 8%)** 알약에 분홍(파괴적이면 빨강) 글자.
- **차단 안내(You've blocked this user)**: 카드 없이 가운데 정렬. 제목 16/600, 설명 12~13 회색, 아래 회색 알약 "Unblock"(높이 40, 좌우 24). 우리 오류 안내("연결하지 못했어요" + "다시 시도")는 이 패턴을 따른다.
- **목록 스켈레톤(Your groove is on its way)**: 왼쪽 색 썸네일 + 회색 막대 2개(모서리 둥글게, 폭 약 55% / 35%, 높이 12, 색 `#3A3A3E`).
- **약관 문구**: 가운데 정렬 11~12 회색, 링크만 분홍. 우리 고정 문구도 가운데 정렬.

### 2-7. 슬라이더·토글·라디오
- 슬라이더: 눈금 7개(세로 짧은 선) 위에 **분홍 세로 알약 손잡이**, 오른쪽 끝 값 "50%". 왼쪽 라벨 + ⓘ.
- 토글: 분홍 `#FF2D7A` 트랙, 흰 손잡이. 꺼짐은 회색.
- 라디오(신고 사유): 흰 테두리 원, 선택 시 분홍 원에 흰 체크.

### 2-8. 목록 행
- 왼쪽 썸네일 44px(모서리 6px, 길이 표시 겹침) + 제목 14px 흰색 + 아래 메타 12px 회색(▶ 18K · Raymond) + 오른쪽 "⋯".
- 선택/재생 중인 행은 제목이 분홍.
- 설정 목록: 아이콘 + 글자 + 오른쪽 chevron, 행 사이 선 없음, 묶음이 카드 하나.

### 2-9. 배지·라벨
- 모델 태그 "v6", "V6-MINI", "FULL SONG": 아주 작은 대문자 12px 회색 또는 분홍.
- "Unlock for full access": 어두운 붉은 알약에 분홍 글자 11px.
- "SAVE 20%": 분홍 바탕 흰 글자 10px 알약.
- 구독 카드 선택: 주황 1px 테두리 + 초록 "Most Popular" 작은 글자.

### 2-10. 토스트·상태
- 토스트: **흰 알약**(모서리 12px) 안에 검정 체크 원 + 검정 글자 14px. 화면 위쪽 또는 재생바 위에 뜸("Added to Liked Songs", "Song reported successfully", "Your profile is completed").
- 진행 중: 상단에 가로로 긴 알약 "Your groove is on its way" + 오른쪽 분홍 원형 로딩 아이콘, 바탕은 흐린 그라데이션.
- 완료: 같은 알약 "Songs ready, tap to play!" + 오른쪽 분홍 원 ▶.
- 목록 로딩: 썸네일 자리 색 블록 + 글자 자리 회색 막대 2줄(스켈레톤).

### 2-11. 상단·하단
- 상단: 왼쪽 원형 뒤로가기(어두운 원 36px) / 가운데 제목 15px(만들기 화면은 "Simple ▾" 드롭다운) / 오른쪽 어두운 알약 "v6-mini ▾".
- 바닥 시트: 위 가운데 회색 손잡이 바, 제목 가운데, 오른쪽 X.
- 하단 탭: 아이콘 5개, 글자 없음, 선택된 아이콘만 어두운 원 안. 그 위에 미니 플레이어(썸네일+제목+아이콘 2개).
- 텍스트 탭: "Recents / Public / Liked" 글자 + 선택 밑줄 흰색.

### 2-12. 플레이어 행동 줄
- 알약 버튼들이 가로로 줄지어 있음: 아이콘 + 숫자/글자("👍 313", "💬 43", "⟳ Remix", "⊕ Playlist"). 바탕 `#2A2A2E`, 높이 36px.

| 접히는 섹션 카드(Lyrics/Styles) | ② 입력 3개(가격·좌석·전달 방식) 각각 카드 하나. 바닥줄에 "근거: …" 채운 칩 + 되돌리기 원 |
| 채운 칩 줄 | ② 전달 방식 5개 선택지 |

## 4. 가져오지 않는 것
- 피드·댓글·공유·재생·구독·프로필·알림 등 기능 구조 전부 (기획서 Won't, 화면 명세표 "절대 넣지 않는 것").
- 하단 탭 5개 (우리는 흐름이 ①→②→③ 한 줄이라 탭이 없음).
- 세리프 글꼴은 ① 첫 화면 제목에만. 나머지 화면은 Suno 내부 화면처럼 산세리프.
